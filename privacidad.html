Política de privacidad de «Zoo Mundo – subidor»

Última actualización: 4 de noviembre de 2026 · English version below

1. Qué es

«Zoo Mundo – subidor» es una herramienta de uso personal que el titular del canal Datos Salvajes (youtube.com/@DatosSalvajesss) ejecuta en su propio ordenador para subir sus propios vídeos a su propio canal de YouTube a través de los Servicios de API de YouTube (YouTube API Services).

2. Uso de los Servicios de API de YouTube y Condiciones de YouTube

Esta herramienta utiliza los Servicios de API de YouTube. Al usar esta herramienta, aceptas quedar vinculado por las Condiciones del Servicio de YouTube (https://www.youtube.com/t/terms).

3. Política de Privacidad de Google

El uso de los Servicios de API de YouTube también está sujeto a la Política de Privacidad de Google (https://policies.google.com/privacy).

4. Qué datos se usan

Al iniciar sesión, el titular del canal concede a la herramienta un único permiso de Google: subir vídeos a su canal (https://www.googleapis.com/auth/youtube.upload). La herramienta solo envía a YouTube el archivo de vídeo y los datos que el propio titular escribe (título, descripción, etiquetas, categoría, visibilidad y fecha de publicación). No lee, modifica ni elimina ningún otro contenido ni accede a datos de otros usuarios o canales.

5. Qué datos se guardan, dónde y durante cuánto tiempo

  • Token de autorización de Google (OAuth): se guarda únicamente en el ordenador del titular, en un archivo local, para no tener que iniciar sesión en cada subida. Se conserva hasta que el titular lo borra o revoca el acceso.
  • Identificador y enlace del vídeo subido: se guardan en un archivo local junto al propio vídeo.
  • No se guarda nada en ningún servidor. No hay base de datos, cookies, analítica ni publicidad.

6. Qué datos se comparten

Ninguno. La herramienta no recopila datos de otras personas y no vende ni comparte información con terceros. Los únicos datos que salen del ordenador son el vídeo y sus metadatos, que se envían directamente a YouTube.

7. Cómo revocar el acceso

El acceso de la herramienta a tus datos se puede revocar en cualquier momento desde la página de configuración de seguridad de Google: https://security.google.com/settings/security/permissions (también en myaccount.google.com/permissions). Al revocarlo, la herramienta deja de poder subir vídeos.

8. Eliminación de datos

  • Para eliminar todos los datos que guarda la herramienta basta con borrar los archivos locales token_youtube.json y youtube-subido.json del ordenador y revocar el acceso como se indica en el punto 7.
  • Si se revoca el acceso desde Google, el token local deja de ser válido y se elimina en el siguiente uso de la herramienta.
  • Puedes pedir en cualquier momento la eliminación de cualquier dato escribiendo a LuismaSolares@gmail.com; se atenderá en un plazo máximo de 7 días. Como la herramienta no guarda datos en servidores, no hay copias en ningún otro sitio.

Privacy Policy – "Zoo Mundo – subidor"

Last updated: 4 November 2026

1. What it is

"Zoo Mundo – subidor" is a personal tool that the owner of the Datos Salvajes channel (youtube.com/@DatosSalvajesss) runs on their own computer to upload their own videos to their own YouTube channel using the YouTube API Services.

2. Use of YouTube API Services and YouTube Terms of Service

This tool uses YouTube API Services. By using this tool, you agree to be bound by the YouTube Terms of Service (https://www.youtube.com/t/terms).

3. Google Privacy Policy

Use of the YouTube API Services is also subject to the Google Privacy Policy (https://policies.google.com/privacy).

4. Data used

When signing in, the channel owner grants the tool a single Google scope: uploading videos to their channel (https://www.googleapis.com/auth/youtube.upload). The tool only sends YouTube the video file and the metadata the owner writes (title, description, tags, category, privacy status and publish time). It does not read, modify or delete any other content, and it does not access data from any other user or channel.

5. Data stored, where, and for how long

  • Google OAuth authorization token: stored only on the owner's computer, in a local file, so the owner does not have to sign in for every upload. It is kept until the owner deletes it or revokes access.
  • ID and URL of the uploaded video: stored in a local file next to the video itself.
  • Nothing is stored on any server. There is no database, no cookies, no analytics and no advertising.

6. Data shared

None. The tool does not collect data from anyone else and does not sell or share information with third parties. The only data that leaves the computer is the video and its metadata, sent directly to YouTube.

7. How to revoke access

The tool's access to your data can be revoked at any time via the Google security settings page: https://security.google.com/settings/security/permissions (also available at myaccount.google.com/permissions). Once revoked, the tool can no longer upload videos.

8. Data deletion

  • To delete all data stored by the tool, delete the local files token_youtube.json and youtube-subido.json from the computer and revoke access as described in section 7.
  • If access is revoked from Google, the local token becomes invalid and is deleted the next time the tool runs.
  • You can request deletion of any data at any time by writing to LuismaSolares@gmail.com; requests are handled within 7 days. Because the tool stores no data on servers, no other copies exist.

9. Contact

LuismaSolares@gmail.com
